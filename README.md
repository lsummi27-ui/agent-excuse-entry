## The excuse

> I missed the deadline while optimising the reminder that was supposed to remind me about the deadline.

## How it works

`main.py` (Python stdlib only) writes the one-line excuse to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is
102 characters, inside the scorer's 1–160 character window.
